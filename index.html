02 / Open source

Du code qui tourne en production

Développeur principal et mainteneur

kube-image-keeper (kuik)

Routage, mirroring et supervision d'images de conteneurs pour Kubernetes. Vos pods démarrent même quand la registry tombe ou vous limite.

GitHub ↗Documentation ↗
  • 750 étoiles GitHub, en production sur plusieurs clusters
  • Environ 790 commits, chart Helm, site de documentation, processus de release
  • Réécriture v3 en cours, première alpha publiée en septembre 2026

Premier contributeur

topomatik ↗

Met à jour automatiquement les labels de topologie des nœuds Kubernetes à partir de l'infrastructure découverte.

  • Moteurs de découverte LLDP, matériel, réseau, hostname et fichiers
  • Gestion des taints, fonctionne sur nœuds virtuels et bare metal
  • Présenté par Enix aux Cloud Native Days France 2026

Talk CND France 2026 (Enix) ↗

Co-développeur

pvecontrol ↗

CLI d'administration de clusters Proxmox VE, écrite en Python.

  • Tests et CI, format de sortie configurable, sanity checks
  • Restauration de VM, évacuation de nœuds
  • Support des clusters derrière un reverse proxy avec authentification par certificat

Contributeur

x509-certificate-exporter ↗

Exporter Prometheus pour les certificats X.509, pensé pour Kubernetes.

  • 950 étoiles GitHub
  • Filtrage des namespaces par labels, probes configurables

Développeur

san-iscsi-csi ↗

Driver CSI pour les baies SAN iSCSI Dothill et Seagate, avec provisionnement dynamique de volumes.

  • Repris par Seagate en janvier 2023 sous le nom seagate-exos-x-csi
  • Retour d'expérience publié sur le blog Enix
